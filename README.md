## 2. Key Architecture & Technical Highlights

### A. Real 360° WebGL Equirectangular Projection (`Three.js`)
* **Mathematical Foundation**: Rather than presenting a flat 2D image, ASTRAVIA utilizes an inverted sphere geometry (`THREE.SphereGeometry(500, 60, 40)` scaled by `(-1, 1, 1)`). Equirectangular panoramic textures are mapped directly to the interior surface.
* **Spherical-to-Cartesian Coordinate Mapping**: Camera pitch ($\phi$) and yaw ($\theta$) are converted into Cartesian coordinates $(x, y, z)$ on each frame:
  $$x = \cos(\phi) \cdot \sin(\theta), \quad y = \sin(\phi), \quad z = \cos(\phi) \cdot \cos(\theta)$$
* **3D-to-2D Hotspot Projection**: Spatial points of interest positioned in 3D world space are continuously projected onto 2D screen coordinates using the camera's projection matrix:
  ```javascript
  vector.project(camera);
  const screenX = (vector.x * 0.5 + 0.5) * containerWidth;
  const screenY = (-(vector.y * 0.5) + 0.5) * containerHeight;
  ```
* **Memory Management & Garbage Collection**: All Three.js resources (`WebGLRenderer`, `SphereGeometry`, `MeshBasicMaterial`, `Texture`) and the `requestAnimationFrame` handle are rigorously disposed in the `useEffect` cleanup return function to prevent WebGL context leaks.

### B. Procedural Soundscape Engine (`Web Audio API`)
* **Zero External Audio Files**: Eliminates 404 network errors and CORS issues. Audio is synthesized in real time using the browser's native `AudioContext`:
  * *Alpine Winds / Lake Waters*: Synthesized Brown and Pink Noise generated via custom `AudioBuffer` curves passed through high-resonance bandpass and lowpass `BiquadFilterNodes`.
  * *Temple Chimes / Coastal Shimmers*: Sinusoidal and triangle waves generated by `OscillatorNode` instances modulated with exponential decay envelopes.
* **Browser Autoplay Compliance**: All sound generation remains dormant until explicit user interaction (audio toggle button), adhering strictly to modern browser autoplay security policies.
* **Cultural Narration**: Built-in speech synthesis via the `window.speechSynthesis` API providing guided audio tours for every location hotspot.

### C. Controlled Multi-Day Itinerary Planner
* **Pure JavaScript Immutability**: All day additions, slot assignments (Morning, Afternoon, Evening), activity reordering (Move Up / Move Down), and deletions are handled through pure array transformations (`filter`, `map`, `reduce`, array slice swapping) without mutating component state.
* **Summary Ribbon**: Real-time analytical computation of total days, scheduled activities, and destination coverage.
* **Re-editing Engine**: Saved itineraries can be reopened from `My Journey` into the planner with URL query parameters (`/itinerary?edit=<itineraryId>`) or pre-seeded with destination highlights (`/itinerary?destination=<destinationId>`).

### D. Persistent Storage (`localStorage`) & Safe Fallbacks
* Persistent state across browser reloads for:
  * `astravia_saved_destinations`: Bookmarked global destinations.
  * `astravia_saved_itineraries`: Custom multi-day travel plans.
  * `astravia_discovered_hotspots`: Exploration progress tracking.
  * `astravia_passport_stamps`: Gamified digital travel stamps unlocked via 360° exploration.
* Every storage access is wrapped in `try...catch` blocks with robust JSON schema validation, ensuring corrupted or missing storage never crashes the application.

## 3. Application Route Directory

ASTRAVIA is a structured multi-page application powered by **React Router v7**:

| Route Pattern | Component | Description |
| :--- | :--- | :--- |
| `/` | `Home.jsx` | Full-screen cinematic video hero (`hero-kashmir.mp4`), floating glass navbar, letter-by-letter animated title, gold accents, global spotlights. |
| `/explore` | `Explore.jsx` | Global exploration hub: real-time search, continent chips, category filters, interactive world map, algorithmic "Surprise Me" modal, comparison tray. |
| `/country/:country` | `CountryDetail.jsx` | Regional and country-level deep dive (e.g., India: Kashmir, Ladakh, Rajasthan, Kerala, Meghalaya, Goa; plus Switzerland, Iceland, Australia, etc.). |
| `/destination/:destination` | `Destination.jsx` | Destination overview: highlights, cultural storytelling, local gastronomy, travel logistics, direct links to Itinerary Builder & 360° Tour. |
| `/journey/:destination` | `VirtualTourPage.jsx` | Full-screen 360° virtual travel experience: WebGL canvas, on-screen zoom HUD (`+`, `-`, `⟲`), clickable hotspots, audio synthesis, info drawer. |
| `/itinerary` | `Itinerary.jsx` | Dedicated travel planner: controlled forms, day stepper, activity reordering, notes, and local persistence. |
| `/my-journey` | `MyJourney.jsx` | Saved journeys hub: saved destinations shelf, saved multi-day itineraries with re-edit capability, and unlocked digital passport stamps. |
| `*` | `NotFound.jsx` | Elegant 404 error page with quick links back to active discovery routes. |

*Note: Backward-compatible aliases (`/discover`, `/destinations`, `/plan`, `/virtual-tour/:id`, `/virtual-journey/:id`) are also preserved.*

## 6. Viva Voce Defense Guide (FEE-II Evaluation)

When presenting to evaluators, highlight these core frontend engineering competencies:

### Q1: Why did you choose Three.js for 360° travel instead of a static image with pan/zoom?
> *"A flat image manipulated with CSS `transform: translate()` distorts at wide angles and cannot simulate spherical perspective. We implemented a genuine Three.js WebGL inverted sphere geometry with equirectangular UV mapping. This allows genuine 360-degree yaw and pitch rotation with spherical-to-Cartesian trigonometry, ensuring an authentic virtual reality experience."*

### Q2: How does your audio system work without external audio files?
> *"External audio files frequently fail due to 404s, slow networks, or CORS restrictions. ASTRAVIA uses the browser's native Web Audio API (`AudioContext`). We synthesize procedural soundscapes using custom Brown Noise buffers, Biquad filter resonance for winds and waves, and OscillatorNodes for ambient chimes. Furthermore, audio only plays upon user gesture to comply with browser autoplay security policies."*

### Q3: How do you handle state persistence and prevent application crashes?
> *"We use `localStorage` for saved destinations, itineraries, and passport stamps. To guarantee resilience against malformed or missing data, all reads are handled with defensive `try...catch` blocks and default fallbacks. State is initialized directly from storage on component mount, eliminating synchronization bugs."*

### Q4: How is data shared across routes in your multi-page application?
> *"We use React Router v7 with dynamic URL path parameters (`/destination/:destination`, `/journey/:destination`) and query parameters (`/itinerary?destination=kashmir` or `/itinerary?edit=id`). This ensures every view is directly linkable, shareable, and bookmarkable without relying on brittle ephemeral in-memory state."*

### Q5: How do you ensure high performance and prevent memory leaks?
> *"In our Three.js and Web Audio components, every `useEffect` returns a dedicated cleanup function that cancels `requestAnimationFrame`, disposes WebGL textures, geometries, and materials, and disconnects active audio nodes. We also use `useMemo` and `useCallback` to prevent unnecessary re-computations."*

## 7. ASTRA — AI Travel Companion

ASTRA is an intelligent, conversational travel assistant built directly into ASTRAVIA to guide global discovery, navigate 360° virtual tours, recommend authentic cuisines, and direct users to travel itineraries.

### Architecture & Security Highlights:
* **Separation of Concerns**: Frontend components (`src/components/astra/`) communicate exclusively with a dedicated Express backend (`server/index.js`), preventing client-side exposure of API keys.
* **Dual AI Modes**:
  * **Live AI Mode**: Directly calls Google Gemini (`gemini-1.5-flash`) or OpenAI (`gpt-4o-mini`) via native server `fetch`.
  * **Local Intelligence Demonstration Mode**: Automatically activated when no API key is configured. Intelligently answers queries using ASTRAVIA's verified destination dataset and routes without hallucinations.
* **Strict Grounding & URL Safety**: A complete structured knowledge base of destinations and verified internal routes is injected into system prompts. Suggested cards navigate via React Router `useNavigate` rather than untrusted model-generated hyperlinks.
* **Network & Token Protection**: Enforces 500-character input limits, limits history windows to 8 turns, and uses 16-second `AbortController` timeouts.

### Running ASTRA (Frontend + Backend):
```bash
# Terminal 1: Start the Backend Server (Port 3001)
cd astravia
npm run server

# Terminal 2: Start the Vite Dev Server (Port 5173 with /api proxy)
cd astravia
npm run dev
```

### Viva Defense: ASTRA Technical Q&A
* **Q6: Why did you build an Express backend instead of calling the AI API from React?**  
  > *"Calling an AI API directly from client-side React code requires exposing secret API keys in browser network headers or Vite environment bundles (`VITE_`), creating severe security risks. By proxying requests through a lightweight Express server, credentials remain protected server-side, request bodies can be validated and rate-limited, and CORS is strictly controlled."*
* **Q7: How does ASTRA prevent hallucinating non-existent destination URLs?**  
  > *"We created a centralized knowledge base (`knowledgeBase.js`) containing only verified Astravia destinations and canonical routes (`/destination/:id`, `/journey/:id`). The backend matches destination references to structured suggestion objects with verified route IDs, allowing the React frontend to resolve them securely using React Router's `useNavigate`."*
* **Q8: How are loading and error states handled in the chatbot UI?**  
  > *"React state manages three distinct UI states: `isLoading` triggers a subtle 3-dot gold bouncing indicator and disables double submissions; `error` renders a dedicated alert banner with a `RETRY` button that resubmits the last failed query; and `AbortController` guards against hanging requests."*
